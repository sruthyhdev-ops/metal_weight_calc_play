# Metal Weight Calculator & PDF

A professional, high-precision utility for mechanical engineers, structural designers, and fabricators to calculate the weight of various metal sections. Developed by **ZMOHI Studios**.

## 🚀 Features
* **Extensive Material Library:** Calculate weights for Mild Steel (MS), Carbon Steel, Galvanized Iron, and more.
* **Structural Profiles:** Supports ISMC (C-Channel), I-Beams, Piping, and custom sections.
* **Bulk Weight Calculator:** Add multiple rows to manage full project material lists.
* **PDF Export:** Generate professional quotes and calculation reports directly from the app.
* **Pro Version:** Ad-free experience with advanced features powered by Google Play Billing.

## 🛠 Tech Stack
* **Framework:** [Capacitor](https://capacitorjs.com/) (Cross-platform Android)
* **Frontend:** React + Vite + Tailwind CSS
* **Monetization:** * **AdMob:** Integrated for standard users.
* **Google Play Billing:** For "Pro Version" in-app purchases.
